# GTA1_Turkce_Ceviri
                                                  GRAND THEFT AUTO 1 TÜRKÇE YAMA v2.0


                                                            KURULUM


GTADATA klasörünü oyununuzun bulunduğu klasöre (GTA klasörüne) atın, Dos sürümü kullanıyorsanız dosbox.conf dosyasını buradaki ile değiştirin, genelde en üst klasörde olur. Oyunu çalıştırın, hem DOS hem Windows uyumludur.


                                                            TEMEL BİLGİLER


Hem GTA1, hem de London 1961 ve London 1969 eklentileri çevrilmiştir. Yamada Türkçe karakter vardır. Yama makine çeviridir. Yamayı çevirmek isteyen veya Türkçe font eklemek isteyen olursa benimle iletişime geçebilir, metinler klasörde mevcuttur, Gman ile .fxt dosyasını değiştirip istediğiniz gibi değiştirebilirsiniz.
